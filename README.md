# C2 Machine Park

A Windows desktop tool for monitoring and maintaining the C2 (ctwo) virtual machine park. It
shows machine status, live session timing, parallel processes and resource groups, and lets you
move, remove, park and comment on machines with drag and drop.

## Download and run (no installation)

1. Open **[Releases](../../releases/latest)** and download `C2-Machine-Park-<version>-win-x64.zip`.
2. Extract the ZIP. It contains one folder, `C2-Machine-Park`.
3. Start `C2-Machine-Park\C2 Machine Park.exe` and sign in with your C2 token.

Everything is inside that folder: the app, its runtime, the documentation, and its local `data`
folder. Requirements are Windows 10/11 x64 and network access to the C2 API.
